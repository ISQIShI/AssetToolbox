# 前端设计规范

状态：已采用。日期：2026-11-10。适用范围：`desktop/src/` 的全部界面工作，包括新增页面、组件、字段类型和文案。

本文是界面设计的唯一规范来源：视觉主张、令牌、布局、组件、状态和文案规则都以这里为准。组件职责、状态流转和请求映射等实现细节见[前端架构](../architecture/frontend.md)；本次从“网页式工作台”改为“桌面软件”的原因见 [ADR 0006](../decisions/0006-desktop-application-shell.md)，处理线主从结构的来历见 [ADR 0004](../decisions/0004-frontend-redesign.md)。令牌的实际取值以 `desktop/src/styles/tokens.css` 为准，本文表格与其同步维护。

## 设计主张

- **产品**：本地资源处理工具。素材文件夹按顺序经过若干步骤（缩放、压缩），写回原处或另存，并且可以续跑和恢复。
- **使用者**：游戏开发者和技术美术。日常开着引擎编辑器、DCC 和 IDE，处理的是成百上千个文件的文件夹，在意每一步做了什么、文件是否安全。
- **主要任务**：配置一条处理线并运行；运行中随时能看到进度并取消；出问题后继续、重试或恢复。

**它是一个桌面软件，不是网页。** 判断一处设计是否合格，先问：把它放在引擎编辑器和 IDE 旁边，是否像同一类东西。具体表现为：

| 网页的做法（不采用） | 软件的做法（采用） |
| --- | --- |
| 系统标题栏下面再放一条带产品名和导航的页头 | 自绘标题栏；左侧活动栏切换工作区 |
| 大标题、宽行距、居中或限宽的“阅读版式” | 13px 正文、30px 控件、紧凑的属性表单和数据表 |
| 操作按钮放在内容末尾或页脚 | 命令放在工作区顶部的命令栏，位置固定 |
| 文字都能选中，按钮显示手型光标，悬停加下划线 | 界面文字不可选中，光标保持箭头，悬停用底色反馈 |
| 网页字体、固定浅色 | 系统界面字体，跟随系统的浅色与深色 |
| 浏览器右键菜单、F5 刷新 | 屏蔽浏览器菜单和刷新，提供自己的快捷键 |
| 没有全局状态位置 | 窗口底部状态栏始终显示当前活动与工具健康状况 |

### 核心隐喻：处理线

处理页左侧的竖线是整个界面的骨架。文件从“来源”出发，自上而下经过编号的步骤，最后到达“写入”。编号就是执行顺序，处理线编号表达步骤顺序；作业中心另以槽位编号表达固定执行位置，两者不混用。

```
■ 来源            UI
│
① PNG 图片缩放     Sharp / libvips
│
② PNG 压缩        ⚠ 缺少依赖          ← 品红编号与缺件图标：缺少依赖
┊
③ JPEG 压缩       已停用              ← 空心节点 + 虚线：停用
│
④ MP3 压缩        LAME 4.0
│
⊕ 添加步骤                            ← 弹出菜单
│
■ 覆盖原文件       备份到 Backups
│
```

### 设计原则

1. **处理线是骨架**：所有和“怎么处理”有关的设置都挂在处理线的某个站点上。不要在处理线之外另开设置区。
2. **层级靠明度，不靠线**：窗口框架最深，侧栏次之，内容面更亮，控件最亮。相邻层级之间最多一条细分隔线。
3. **强调色只有一种**：`--accent` 表示“当前选中”“主命令”和键盘焦点。其余彩色只表达状态（成功、警告、失败、缺依赖），不作装饰。
4. **路径和哈希用等宽字体，并且可以选中复制**：它们是需要逐字核对的数据。其他界面文字用系统字体且不可选中。
5. **命令位置固定**：每个工作区的主要命令在顶部命令栏或详情标题行右侧；同一命令不随内容长短移动。
6. **作业全局可见**：同一安装按配置的 1–8 个槽位执行无资源冲突的作业（默认 2），其余等待。本会话作业在处理页显示于右侧概览栏，在其他页面显示于工作区底部的作业栏，状态栏给出一句话状态；跨入口等待与执行状态在作业中心查看。
7. **结果有固定位置**：处理页右侧的概览栏常驻显示“会处理哪些格式、扫描到多少文件、处理进度与结果”。扫描和处理不改变当前选中的站点，也不需要用户去找结果。
8. **说明不占版面**：区块里只留标签和状态。成段的解释收进标题旁的说明图标（`Tip`），取值范围只在越界时作为错误出现。页面标题下可以有一行副标题。

### 外观（浅色与深色）

- `core/theme.ts` 在 `<html data-theme>` 上写入 `light` 或 `dark`，`tokens.css` 用 `:root[data-theme='dark']` 重定义同名令牌。组件里不写主题分支。
- 默认跟随系统（`prefers-color-scheme`），系统切换时即时生效。活动栏底部的外观按钮每点一次就在浅色与深色间切换一次；切换后的外观与系统一致时记为“跟随系统”，否则记为固定的浅色或深色。选择保存在 WebView 的 `localStorage`，不进入核心配置。
- 新增或调整颜色时，两套取值都要在所在背景上达到 4.5:1。

### 缺少依赖标记

`.missing-swatch` 是 14px 的品红缺件图标：虚线圆角方框里一个感叹号，表示“这里缺了一块”。它用 CSS 遮罩绘制，颜色取 `--missing`，与界面其他线条图标的线宽一致。它只能表示“处理工具缺少依赖”，出现在处理线站点、命令栏、步骤编辑器提示、工具页和状态栏；活动栏的“工具”项用品红计数徽标。不要把它用于其他错误。

### 字体

| 角色 | 字体栈 | 说明 |
| --- | --- | --- |
| 界面 | `Segoe UI Variable Text` → `Segoe UI` → `Microsoft YaHei UI` | 系统界面字体，与 Windows 自身一致；中文由雅黑 UI 显示 |
| 路径、哈希、扩展名 | `Cascadia Mono` → `Consolas` | 只用于需要逐字核对的数据 |

不打包任何字体文件，也不引入在线字体。全局开启 `font-variant-numeric: tabular-nums`，让进度、计数和体积对齐。

### 字号

只用五级：

| 令牌 | 大小 | 用途 |
| --- | --- | --- |
| `--t-small` | 12px | 提示、副标题、表头、状态栏、标题栏、活动栏标签 |
| `--t-body` | 13px | 正文、控件、列表项、分组标题（600）；行高 1.5 |
| `--t-title` | 15px | 概览栏与作业卡片标题、对话框标题、落地区标题 |
| `--t-heading` | 18px | 页面与站点标题（`h2`） |
| `--t-figure` | 20px | 扫描结果、任务进度与处理结果的关键数字；作业卡片的百分比为 28px |

字重只用 400 和 600。不使用斜体、全大写和字间距放大的小标签。活动栏计数徽标和处理线节点编号是 11px 的图形内数字，不算正文。

### 间距、圆角与尺寸

- 间距：`--s-1` 到 `--s-7` 对应 4、8、12、16、20、24、32px。
- 圆角按层级：控件 6px（`--r-control`），分组面板 8px（`--r-panel`），弹出菜单与工作区左上角 10px（`--r-float`），状态徽标与处理线节点为全圆角。
- 面板不描边：分组面板、数据表外框、信息条用 `--control` 底色加 `--shadow-card`（一圈 5% 的发丝线加 1px 投影）从内容面上分出来。浮层用 `--shadow-float`。
- 窗口框架：标题栏 `--titlebar-height: 36px`，活动栏 `--activity-width: 64px`，状态栏 `--status-height: 24px`，命令栏 `--command-height: 44px`。
- 侧栏：处理线 `--rail-width: 264px`，任务列表 `--list-width: 288px`，概览栏 `--inspector-width: 304px`；窗口不超过 1160px 时为 228px、252px 与 272px。
- 控件：普通 `--control-height: 30px`，小号 `--control-small: 24px`；属性表单标签列 `--label-width: 128px`（紧凑窗口 108px）。
- 内容区表单最大宽度 `--measure: 760px`，边距 `--pane-padding: 20px`（紧凑窗口 16px）。

## 布局

### 窗口骨架

```
┌──────────────────────────────────────────────────────────────────┐
│ ▣ 资源工具箱 │ 来源文件夹名                           ─  ☐  ✕   │ 标题栏 36px，可拖动
├────┬─────────────────────────────────────────────────────────────┤
│处理│ 信息条（错误 / 成功 / 警告，按需出现）                       │
│活动│ ┌─────────────────────────────────────────────────────────┐ │
│恢复│ │ 当前工作区：命令栏 + 侧栏 + 内容区                       │ │
│工具│ │                                                         │ │
│    │ └─────────────────────────────────────────────────────────┘ │
│ ◐  │ 作业栏（有作业时）                                           │
├────┴─────────────────────────────────────────────────────────────┤
│ ● 就绪                              1 个任务可继续  处理工具 4/4  │ 状态栏 24px
└──────────────────────────────────────────────────────────────────┘
```

- 原生窗口关闭系统边框（`decorations: false`），标题栏由 `TitleBar.vue` 绘制：应用图标、名称，一条短竖线后是当前来源文件夹名，右侧是最小化、最大化、关闭。空白处带 `data-tauri-drag-region`，可拖动窗口、双击最大化。
- 活动栏、标题栏、状态栏同为 `--chrome`；工作区是从框架上抬起的一块，左上角圆角。
- 窗口是不透明的，框架用纯色 `--chrome`。不使用系统材质（Mica、Acrylic）：它的色调来自壁纸，会让框架与工作区的色调不一致。
- 外壳是纵向 flex。**不要改用 CSS Grid 的固定行模板**：信息条和作业栏按需出现，Grid 自动放置会把工作区挤进错误的行。
- 工作区占满剩余高度，各分栏自己滚动，窗口本身不滚动（`body` 为 `overflow: hidden`）。
- 所有内容左对齐。只有数字列右对齐。

### 工作区

| 工作区 | 顶部命令栏 | 左栏 | 内容区 |
| --- | --- | --- | --- |
| 处理 | 步骤统计、写入策略；保存配置、扫描预览、开始处理 | 处理线 | 选中站点的编辑器；右侧是常驻的概览栏 |
| 活动 · 任务 | 视图切换（任务 / 作业队列）与一句说明；命令在详情标题行右侧（继续未完成、重试失败项） | 可搜索的任务列表，每行带进度条 | 进度、体积、详情、备份与恢复四个分组。体积显示已完成文件的处理前、处理后与变化（节省为成功色、增大为警告色，带百分比），核心没有给出体积时整组不显示；详情里的来源、写入、备份各带一个“在资源管理器中打开”的图标按钮，覆盖原文件的任务“写入”打开来源文件夹 |
| 恢复 | 来源选择（任务的备份 / 独立备份文件夹）与检查命令 | 无 | 检查结果：筛选工具栏、数据表、底部的计数分页与恢复命令 |
| 工具 | 工具健康状况；刷新依赖状态 | 无 | 处理工具列表（缺依赖的排在最前并展开）、识别的资源类型、核心目录 |

### 窗口尺寸

- 原生窗口默认 1280×850，最小 840×620。最小尺寸下不能出现横向滚动，E2E 会检查。
- 处理页是三栏：处理线、编辑器、概览栏。窗口不超过 1040px 时概览栏移到下方成为一条，只留作业与四个扫描数字；既没有作业也没有扫描结果时这一条不显示。
- 这是桌面软件，不做手机宽度的布局。低于 840px 只可能出现在浏览器调试中，不需要适配。
- 内容区表单按容器宽度调整：写入方式的两个选项在 520px 以内纵向排列；参数行在 420px 以内改为标签在上。

## 组件

### 图标

`Icon.vue` 提供一组自绘的 16px 单色线条图标，颜色跟随文字，不引入图标库。图标只作辅助识别：带文字的按钮图标在文字左侧；只有图标的按钮必须有 `aria-label` 和 `title`。新增图标在 `Icon.vue` 的路径表里登记，线宽和网格保持一致。

### 按钮

| 类 | 外观 | 用途 |
| --- | --- | --- |
| `.button` | 控件底色加细边框 | 普通命令 |
| `.button.primary` | 强调色实心 | 每个区域最多一个，表示下一步最该做的事 |
| `.button.quiet` | 无边框，悬停才有底色 | 次要命令、关闭 |
| `.button.danger` | 红色文字，悬停红色浅底 | 删除步骤等破坏性命令，放在命令行最右侧 |
| `.button.small` | 24px 高 | 步骤命令、表格工具栏、分页 |
| `.button.icon-only` | 正方形 | 只有图标的命令 |

按钮文字说清楚会发生什么。有快捷键或需要补充说明的命令用 `Tip` 包裹给出提示（见下文“下拉选择与提示”）。停用的按钮要能从周围文字看出原因，例如命令栏会写出哪一步缺少依赖。

### 表单

- 字段是属性表单的一行：`.field` 两列，标签在左（`.label`，`--label-width` 宽），控件在右，提示（`.hint`）在控件下方。`.field.stacked` 是标签在上的变体，只用于横向排布的来源选择栏。
- 每个控件都必须有关联的 `<label for>`，ID 用 `useId()` 生成，不能用标签文字拼 ID。
- 相关字段放进 `.group` 分组面板，面板内第一行是 `h3` 标题。
- 路径一律用 `PathField`：等宽输入框加“浏览…”按钮，可直接粘贴路径。
- 参数一律由 `ParameterFields` 按核心返回的字段描述渲染。数值框限宽 140px，下拉框限宽 320px；扩展提供的 hint 显示在控件下方。取值范围平时不显示，当前值越界或为空时在控件下方以错误色提示“请输入 a–b 之间的值”，输入框边框变为错误色并带 `aria-invalid`。
- 数值参数用 `NumberField`：104px 宽的数字框，右侧内缘是一对步进按钮；字段同时有上下界且档位不超过 200 个（质量、级别、比例）时左侧配滑块，已选部分为强调色。像素宽度这类大范围只有数字框。数字框是唯一带标签、可聚焦的控件，方向键即可步进；滑块与步进按钮是鼠标辅助，带 `aria-hidden` 且不进入 Tab 顺序。
- 勾选框和单选是自绘的（`appearance: none`），勾选色为强调色。立即生效的开关用 `input.toggle`（“启用此步骤”）。
- 下拉选择一律用 `SelectBox`，不使用原生 `<select>`。
- 两三个互斥选项用 `.segmented` 分段选择（恢复来源、恢复状态筛选），内部是视觉隐藏的单选框。

### 下拉选择与提示

行为由无样式库 Reka UI 提供，外观全部来自令牌；视图只使用项目自己的封装，不直接使用 Reka 组件。原因见 [ADR 0018](../decisions/0018-headless-ui-primitives.md)。

- **`SelectBox`**：触发按钮沿用 `.select` 的外观（控件底色、细边框、右侧箭头），展开时边框为强调色。弹出列表是 `--control` 底、8px 圆角、`--shadow-float` 阴影，根列表宽度不小于触发按钮，最高 320px。选项最小行高 28px，当前项打勾，键盘或鼠标指向的项用 `--hover`。可自然分组的选项用多级菜单，分支右侧显示箭头，只展开子菜单，不提交值；长标签换行，窗口边缘自动翻转定位。比较符、布尔值等短列表保持单层，不人为增加层级。
- 多级菜单支持上下方向键导航、右方向键展开、左方向键返回上一级、Enter/空格选择、Esc 关闭及焦点归还。分支可点击或悬停展开；只有叶子可选。禁用字段关闭已打开的菜单，不能通过挂在 body 的浮层绕过禁用状态。
- 属性表单里的下拉框限宽 320px；`.field.stacked` 里占满宽度。
- 尚未选择时显示占位文字（`--text-3`），不提供空选项。目录外的旧值作为一个带“（目录外的值）”后缀的选项保留。
- 每个 `SelectBox` 必须有 `id` 配合 `<label for>`，或者有 `aria-label`。选项带 `data-value`（核心 ID），供原生 E2E 定位。
- **`Tip`**：包裹单个可聚焦控件。悬停约 0.45 秒或键盘聚焦时出现，一行说明加可选的快捷键（`kbd` 样式）。默认在控件下方，活动栏的提示在右侧。提示只是补充：只有图标的按钮仍然必须有 `aria-label`。
- 被截断的数据（如作业编号）显示全文时可以继续用原生 `title`。
- 需要新的浮层类控件时，同样先封装成项目组件，样式写在 `styles/base.css` 并只引用令牌。

### 确认对话框

`ConfirmDialog` 只用于**无法撤销**的操作，目前有两处：删除步骤；覆盖原文件且不备份时开始处理。可以撤销或代价很小的操作（停用步骤、切换页面、关闭作业栏）不弹对话框。

- 遮罩用 `--scrim` 压暗整个窗口，对话框居中，宽度不超过 420px，`--control` 底、8px 圆角、`--shadow-float` 阴影。
- 标题是一个问句，说清要做什么；正文一两句说明后果。按钮在右下：左边“取消”，右边是动作本身的名字（“删除”“继续处理”），不写“确定”。破坏性动作用 `.button.danger-solid`（红色实心）。
- 打开时焦点在“取消”上；Esc 等同取消；焦点被限制在对话框内，关闭后回到触发的控件。
- 同一时间只有一个对话框。通过 `bench.confirm()` 发起，不要在组件里各自实现。

### 右键菜单

`StepMenu` 是处理线步骤的右键菜单，内容与步骤编辑器的命令相同：上移、下移、停用/启用、删除步骤…（带省略号的项会再弹确认）。打开菜单的同时选中该步骤。

- 外观与下拉列表一致（`.menu-popup`、`.menu-item`）：行高 28px，行首图标，行尾可标快捷键；破坏性项为红色，与其他项之间有分隔线。
- 右键菜单只是快捷入口：每一项都必须能在别处用按钮或键盘完成，不能有只存在于右键菜单里的功能。
- 生产构建屏蔽了浏览器右键菜单，所以只有显式提供菜单的地方右键才有反应；目前只有处理线步骤。

### 处理线站点

- 端点（来源、写入）是 10px 圆角方块；步骤是 20px 圆形编号，平时为控件底色加细边，选中时填成强调色；添加步骤是空心圆加号。节点外有一圈与所在行底色相同的描边，把竖线在节点处断开。
- 停用步骤：空心编号，该段竖线变为虚线，副标题写“已停用”。
- 缺少依赖：编号底色变为品红，副标题显示缺件图标和“缺少依赖”。
- 每个站点是一个圆角列表项按钮，悬停显示 `--hover`，选中显示 `--accent-wash` 且 `aria-current="true"`。端点带 `data-station`，步骤带 `data-step-id`，供测试定位。
- “添加步骤”使用三级非模态选择器：资源分组 → 资源格式 → 操作，例如“图片 → PNG → 图片缩放”。首层显示类别及格式摘要，次层显示该类格式与扩展名，末层仅列出该格式可用的操作；选到操作才创建步骤。标题显示当前层级和路径，提供逐级返回按钮。搜索只作用于当前层的名称、ID 和说明；没有匹配项时给出提示。内容从目录生成，缺依赖的组合仍可添加，由步骤编辑器提示获取方式。
- 选择器用 `position: fixed`，由 Floating UI 按添加按钮定位：默认在下方左对齐，空间不足时翻到上方，始终留在窗口内，高度不超过可用空间（160–360px）。
- **排序**：按住步骤拖动超过 5px 进入排序，其余步骤实时让位，被拖动的步骤抬起并显示强调色边框；松开即生效，这次松开不会切换选中项。键盘用 `Alt+↑` / `Alt+↓` 移动当前聚焦的步骤，焦点跟随。作业运行时不能排序；来源、写入等端点不参与排序。
- 选择器用 `position: fixed` 按按钮定位，宽 320px、高度最多 360px，下方空间不足时向上展开并限制在窗口内；仅选项列表滚动，标题和搜索始终可见。点击别处、焦点移出、窗口尺寸变化、处理线滚动或进入忙碌状态时关闭。
- 打开和切换层级时聚焦搜索框并清空搜索；上下方向键移动选项，Home/End 定位首尾（搜索框中保留文本编辑行为），Enter/空格激活按钮，格式或操作按钮上按左方向键返回上一级。Esc 退出及添加完成后焦点回到添加按钮；取消选择不修改处理线。

### 命令栏、步骤编辑器与工具列表

- 处理页命令栏左侧显示启用步骤数和当前写入策略。写入策略是一个可点击的小标签，点击定位到“写入方式”；不备份时为警告色。缺依赖时改为显示品红提示和“查看获取方式”入口。
- 同一操作切换处理工具时保留操作参数，工具参数改为目标操作适配器的默认值；切换操作才重置两组。工具参数标题包含工具与操作名称，不能显示其他操作的专属字段。
- 步骤编辑器自上而下：标题行（左侧是标题与“第 N 步，共 M 步”，右侧是只有图标的步骤命令——上移、下移、恢复默认参数、删除步骤——和“启用”开关，命令带 `Tip` 与 `aria-label`）；缺依赖提示；“步骤组合”分组；步骤过滤；操作参数分组；工具参数分组。
- 来源站点：还没有来源文件夹时，顶部显示整块可点的落地区（虚线框、文件夹图标、“选择要处理的文件夹”），下方仍保留可粘贴路径的 `PathField`。从资源管理器把文件夹拖进窗口时，编辑区罩上强调色虚线框并提示“松开后设为来源文件夹”；松开后设为来源并选中来源站点。拖入的不是文件夹时拒绝并说明，作业运行时不接受拖入。
- 工具列表是一个面板里的可展开行，使用原生 `details/summary`，行首箭头随展开旋转，行尾是状态徽标（`.state`）。支持 Enter 和空格操作。
- 所有 `details` 折叠面板展开和收起时有 0.15 秒的高度过渡（`::details-content` 与 `interpolate-size`），不需要脚本。
- 依赖管理位于展开行内，显示当前/核验版本、来源域名与状态。根据状态提供“获取并安装”“更新到核验版本”“修复安装”或“重新安装”；手动项保留说明及获取链接。所有安装动作在作业运行时停用；进度与取消使用作业栏。不要把核验版本写成上游最新版。

### 概览栏

`RunInspector` 常驻处理页右侧，`--pane` 底色，自上而下三块：

- **当前作业**：有本会话作业时显示作业卡片（见“作业栏”）。运行中的卡片有一圈强调色细边。
- **扫描**：扫描前标题是“概览”，下面是一条虚线提示；扫描后标题改为“扫描结果”，显示四个数字（文件、原始体积、会经过步骤、输出冲突，冲突非零为错误色）与“重新扫描”。配置在扫描后改动过，或扫描被取消，用警告信息条说明。来源条件排除了文件时给出一行说明；需要注意的问题列在数字下方。
- **资源格式**：一张表，按类别分组列出目录中的每种格式和启用的步骤数；扫描后补上文件数与体积两列，并在类别行显示合计。没有启用步骤的格式用次要文字色。扩展名只在扫描前显示。

概览栏只读工作台状态，不保存自己的状态；它不是站点，不改变处理线的选中项。

### 活动工作区

`ActivityView` 顶部是一条 `--pane` 底色的切换栏：左侧是“任务 / 作业队列”分段选择（任务带数量），右侧一句话说明当前视图是什么。下面是对应的子视图，各自保持原有布局。活动栏的“活动”在两个视图下都是选中状态；再次进入时回到上次看的视图，从作业结果“查看任务”、状态栏“N 个任务可继续”进入时直接落在任务视图。

恢复页的“任务的备份”选中任务即开始检查，旁边的按钮是“重新检查”；没有结果时内容区居中显示一个图标和一句引导。

### 作业栏

- `JobDock` 有两种摆放：处理页放在概览栏顶部（`variant="panel"`，一张卡片，纵向排布，运行中显示 28px 的百分比，结束后前两个数字放大）；其他页面停靠在工作区底部（`--pane` 底色，横向一行）。两种摆放是同一个组件、同一份状态和命令，类名与 `data-job-id`、`data-state` 相同，任何时刻只渲染一个。窗口不超过 1040px 时处理页的卡片也改用横向布局。
- 运行中：标题、阶段、进度条、`已处理 / 总数`、耗时、取消；第二行是当前文件（等宽、单行省略）。总数未知时进度条来回扫动。
- 结束后：结论图标与文字（已完成 / 完成，N 个失败 / 已取消 / 未完成），关键数字，打开报告、查看任务、关闭。
- 预览类作业（扫描预览、检查备份）成功拿到结果后自动收起，结果显示在所属页面（扫描结果在概览栏）；失败时保留作业栏显示错误。
- 关闭作业栏只隐藏界面，不删除任务和报告。

### 状态栏

窗口最底部的一行，始终可见。左侧是一句话活动状态（就绪 / 正在运行：作业名 / 正在安全退出），带状态圆点；右侧是可点击的概况：可继续的任务数（跳到任务页）、处理工具可用数（跳到工具页，缺依赖时为品红并带缺件图标）。状态栏只放全局事实，不放命令。

### 信息条与徽标

- `.callout` 是圆角信息条，按 `danger / warn / ok / missing` 取对应浅色底，行首有状态图标或缺件图标。全局错误和成功提示显示在工作区顶部，可以关闭；局部提示放在对应内容上方。
- `.badge` 是全圆角小标签，用于对象的状态（任务状态、工具可用性、恢复文件状态）。行内的状态文字用 `.tone`。

### 表格

数据表放在不描边的圆角面板里（`.frame`）或独立滚动区里。表头吸顶，`--pane` 底、12px 常规字重；行高紧凑，悬停有底色；数字列右对齐且不换行。已勾选的行使用 `--accent-wash`。

## 交互约定

- **选择与光标**：`body` 为 `user-select: none; cursor: default`。输入框、`.path` 和 `.selectable`（错误信息、安装说明）可以选中复制。按钮不使用手型光标。
- **悬停与选中**：悬停用 `--hover` 底色；列表中的当前项用 `--accent-wash`；活动栏当前项另有强调色竖条。不使用下划线表示可点击。
- **快捷键**：`Ctrl+1`–`Ctrl+4` 切换工作区；`Ctrl+S` 在处理页保存配置。快捷键通过 `Tip` 的 `shortcut` 显示在提示里。
- **浏览器行为**：生产构建屏蔽浏览器右键菜单（文本输入框除外）以及 F5、Ctrl+R、Ctrl+P、Ctrl+F 等浏览器快捷键，避免刷新丢失未保存的编辑。开发模式保留，便于调试。
- **关闭窗口**：标题栏关闭按钮调用原生 `close()`，与系统关闭走同一条路径；有作业时先协作取消。
- **排序与右键**：处理线步骤可拖动排序，也可用 `Alt+↑` / `Alt+↓`；右键步骤打开命令菜单。

## 状态语义

| 状态 | 颜色 | 出现位置 |
| --- | --- | --- |
| 已完成、可用、节省体积 | `--ok` | 任务状态、工具状态、体积变化为减少 |
| 可继续、已取消、结果过期、体积增大、检查不完整 | `--warn` | 任务状态、作业结论、扫描结果 |
| 失败、冲突、错误、无法读取 | `--danger` | 作业结论、恢复状态、任务状态 |
| 缺少依赖 | `--missing` 加缺件图标 | 活动栏、处理线、步骤提示、工具页、命令栏、状态栏 |
| 中性（正在处理、已开始恢复、可恢复） | `--text-2` | 其余状态 |

体积变化统一用 `sizeChange()` 格式化：节省显示为 `−2.0 KB`（绿色），增大显示为 `+100 B`（警告色）。不要直接显示 `savedBytes` 的原始符号。

## 文案

### 词汇表

界面用使用者的语言，架构文档用实现的语言。两者对应如下，新增界面文字时沿用左列：

| 界面用词 | 架构 / 协议术语 |
| --- | --- |
| 处理线、步骤 | pipeline、step |
| 资源类型 | resource type |
| 操作 | operation |
| 处理工具 | provider |
| 操作参数 / 工具参数 | `parameters` / `providerOptions` |
| 来源文件夹 | `sourceDir` / `folder` |
| 写入方式：覆盖原文件 / 另存到新文件夹 | `saveMode`: `overwrite` / `saveAs` |
| 替换前备份原文件 | `backupEnabled` |
| 扫描预览 | `preview` |
| 检查备份 | `restore-preview` / `restore-export-preview` |
| 任务的备份 / 独立备份文件夹 | 任务恢复 / `restore-export` |
| 外观：浅色 / 深色，与系统一致时注明“跟随系统” | `theme`（仅前端） |

### 动作名称一致

同一个动作从按钮到作业栏标题使用同一个名字：

| 按钮 | 作业栏标题 |
| --- | --- |
| 扫描预览 | 扫描预览 |
| 开始处理 | 处理资源 |
| 继续未完成 | 继续未完成 |
| 重试失败项 | 重试失败项 |
| 检查备份 / 检查独立备份 / 重新检查 | 检查备份 |
| 恢复所选 N 项 | 恢复所选文件 |

### 写法

- 用平实的动词和句子，句号结尾。不用感叹号，不道歉，不用“您”。
- 错误说清楚发生了什么、怎么办：“第 2 步的处理工具缺少依赖，安装或停用后才能开始处理。”
- 空状态说明这里会出现什么、怎样开始：“还没有任务。在“处理”页开始处理后，进度会保存在这里。”
- 计数写成句子或带单位的短语（“3 / 4 个步骤已启用”），不要用 `A · B · C` 拼接元数据。
- 不在标题上方加小标签，不用全大写英文标签，不用“WORD — 片段”式标题。

## 动效

主动动效只有三处：作业栏进度条的宽度过渡与总数未知时的扫动；状态栏圆点在忙碌时的明暗变化。其余都是对操作的直接响应，不超过 0.16 秒：开关滑块、展开箭头旋转、折叠面板的高度过渡；切换页面时新页面淡入（0.12 秒，旧页面立即移除，不做离场动画）；切换站点、扫描数字与作业卡片出现时用 `.rise` 轻微上浮淡入。按钮的底色不做过渡（透明与实色之间插值会闪出灰色）。`prefers-reduced-motion` 时全部动画缩短到近似为零。

## 可访问性底线

- 键盘可以到达所有操作，焦点统一显示 2px `--accent` 轮廓。标题栏的窗口按钮不进入 Tab 顺序（系统快捷键已覆盖）。
- 图标性元素（图标、节点、缺件图标、色键）设 `aria-hidden`，含义由文字表达；只靠颜色区分的状态必须同时有文字。
- 文字与所在背景的对比度不低于 4.5:1，浅色与深色都要满足；`--text-3` 只用于占位、停用和装饰线。
- 作业栏是 `role="status"` 且 `aria-live="polite"`；全局错误是 `role="alert"`。

## 扩展界面的方式

- **新增资源类型、操作或处理工具**：不需要改前端。添加步骤菜单、步骤编辑器、工具页和识别类型表都由 `bootstrap` 返回的目录驱动。
- **新增参数字段类型**：在 `ParameterFields.vue` 增加分支，并在扩展契约中登记；保持“标签在左、提示在控件下方”。
- **新增工作区**：在活动栏加一项（图标、两个字的名称、`Ctrl+数字`），命令放顶部命令栏，优先采用“侧栏 + 内容区”的主从结构；作业相关逻辑放进 `core/workbench.ts`，不要在视图里直接调用公共作业 API。
- **新增作业类型**：在 `workbench.ts` 的 `JobKind` 中登记，并决定它是否属于“预览类”（结果在页面内显示、作业栏自动收起）。处理页的概览栏会显示任何类型的本会话作业。

## 在浏览器中调试界面

在 `desktop/` 执行 `npm run dev:web`，打开 `http://127.0.0.1:1420`。开发模式下检测不到 Tauri 时，`core/api.ts` 改用 `core/preview-core.ts` 模拟核心：生成样例配置、任务、扫描和恢复结果，并模拟作业进度。它不读写任何文件，生产构建会剔除。浏览器中没有原生窗口，标题栏不显示窗口按钮，也不能拖动。

| 地址参数 | 效果 |
| --- | --- |
| `?missing` | pngquant 显示为缺少依赖 |
| `?empty` | 没有任务 |
| `?missing-auto` | LAME、Sharp 缺失，模拟安装后恢复可用，不下载或写文件 |
| `?updates` | 模拟存在新的核验版本 |
| `?duration=6000` | 模拟作业持续的毫秒数，默认 4000 |

模拟核心只用于看效果。行为验收以组件测试和原生 E2E 为准。

Vite 文件监听排除 `src-tauri/`，避免 Windows 原生构建锁定 EXE 时使浏览器预览报 `EBUSY` 并退出；前端源码热更新仍正常工作。

## 改动前后的核对清单

1. 在 1280×850 和 840×620 下截图，确认没有横向滚动、文字截断后仍可辨认；处理页在两种宽度下概览栏分别在右侧和下方。
2. 浅色与深色各看一遍：层级分明，状态色可读。
3. 运行一次扫描、一次处理、一次检查备份，看概览栏与作业栏的运行、完成和收起，以及状态栏文字。
4. 打开 `?missing`，确认处理线、命令栏、活动栏、状态栏和工具页都显示缺依赖。
5. 用 Tab 键走一遍当前页面，焦点可见且顺序合理；试 `Ctrl+1`–`4` 与 `Ctrl+S`。
6. 在原生窗口中拖动标题栏、双击最大化、最小化、关闭，并从窗口边缘调整大小。
7. 新增的颜色、字号、间距都来自令牌；新增的文字符合词汇表。

## 不采用的方向

以下方向被考虑后否决，后续调整不要回到这些做法：

- **网页式页头与页脚**：系统标题栏下再放一条“产品名 + 标签”的顶栏，运行按钮放在页面底部。这是 1.0.0 之后一轮设计的做法，看起来像一个被装进窗口的网站。
- **阅读版式**：24px 标题、1.6 行距、38px 控件和 720px 文章宽度适合文档，不适合反复操作的工具。
- **网页字体**：打包 IBM Plex 让界面与系统其他软件不一致，还增加了分发时的字体许可义务。
- **卡片堆叠**：把每个设置区做成同样圆角、同样明显阴影的卡片从上到下长滚动。分组面板可以用，但只在内容区内、只用发丝线级别的 `--shadow-card`，并且由处理线决定当前显示哪一组。
- **描边面板**：每个分组、表格、信息条各画一圈 1px 边框，层层套框，读起来像网页表单。已改为底色加 `--shadow-card`。
- **常驻的说明段落与范围提示**：每个区块下面一两行解释、每个数字框下面一行“范围 a–b”，看起来像文档页。说明收进 `Tip`，范围只在越界时出现。
- **处理线末端的“扫描结果”站点**：扫描后自动跳到这个站点，会打断正在编辑的步骤，而且处理结果另在底部作业栏，两处都要找。已由概览栏取代。
- **品红棋盘格（“丢失贴图”）标记**：小尺寸下只是一块杂色马赛克，看不出含义，也与线条图标不协调，已换成缺件图标。
- **三态循环的外观按钮**（跟随系统 → 浅色 → 深色）：系统为浅色时从浅色切到深色要点两次。
- **品牌绿色主色**：与“成功”状态冲突。品牌绿只留在标题栏的应用图标上。
- **全大写英文眉标**（WORKSPACE、PROCESSING 等）：对中文用户没有信息量。
- **暖米色底配陶土色、黑底配荧光色**：这是生成式界面的常见默认风格，与工具软件的气质无关。
- **带外观的组件库**（Element Plus、Naive UI 等）：默认是网页后台的外观和密度，会与令牌体系并存两套主题。只引入无样式的行为库。
- **原生 `<select>` 与 `title` 提示**：弹出列表和提示由浏览器绘制，不受令牌控制，已换成 `SelectBox` 与 `Tip`。
- **系统窗口材质（Mica）**：曾在 Windows 11 上让框架透出材质。实机上框架随壁纸带上绿色、暖色，与工作区的冷灰不协调，已撤回（[ADR 0020](../decisions/0020-activity-workspace-and-number-controls.md)）。
- **“任务”“作业”各占一个活动栏项**：两个相邻概念放在导航层，用户要先分清区别才知道去哪一页。已合并为“活动”工作区里的两个视图。
- **手机宽度适配**：窗口最小 840px，移动端布局只会增加维护成本。

## 音频结果约定

沿用处理线参数编辑与全局作业栏。纯分析摘要注明不写素材；增益和归一化默认另存，无备份覆盖不可执行。作业结束后用可折叠测量明细展示输入/输出 LUFS、真峰值和实际增益，明确区分无法测量、未达目标和未提交，不用成功颜色掩盖这些状态。明细最多 100 条，完整报告可打开；紧凑窗口内换行、作业栏滚动。

## 存储维护交互

工具页使用默认折叠面板，沿用现有色彩和表格令牌。保留天数、预览、勾选清单、清理按钮按顺序排列；默认 30 天且不自动勾选。受保护记录同时显示原因，不能只用颜色表示；清理按钮展示选择数量。表格限高独立滚动，窄窗口允许 ID 和说明换行，不能引入横向溢出。翻页清空选择、修改天数清空预览，执行中禁用表单并显示“正在维护存储”；错误不自动重试删除。完整边界见[存储维护](../architecture/storage.md)。

## Agent 接入面板

工具页使用“Agent 接入与服务管理”折叠面板，与存储维护共享 `.tool-panel-heading`：控件底色、细边框、6px 圆角、44px 最小标题行、自绘折叠箭头，右侧是说明与状态徽标；不额外添加底部分隔线或外边距。展开后依次为“本机服务 → 访问配置 → Agent 连接”，用细分隔线组织，不嵌套同样的卡片。每区标题右侧放相关命令，目录使用左标签/右等宽文本框，权限为两列复选项。

配置运行时禁用；刷新状态保留未保存的表单输入。显示实际端点和持有入口关系，不把停止请求当成已停止。stdio/HTTP 连接配置以可选择复制的文本框展示，令牌只显示文件位置。离开页面或收起面板只停止观察轮询，不能停止服务；主窗口退出由核心收尾。浏览器预览明确说明不真实监听。

## 资源类别与格式

类别来自核心 `resourceTypes[].kind`，图片为 image，音频为 audio；JPEG/PNG 是图片组内的独立格式。工具页与处理页概览栏的格式表以类别分组；概览栏在扫描后同时显示类别合计和逐格式明细，目录里已不存在的格式归入“其他”并保留文件数；步骤格式和过滤格式值使用“类别 → 格式”多级菜单，添加步骤在其后继续选择操作。未知类别显示原 kind，不能隐藏未来扩展。不要把全部图片合并成一个格式 ID，也不把类别标题做成批量添加步骤的命令。

过滤器将 resource-kind/resource-type 分别显示为“资源类别/资源格式”；等于/不等于时从目录选择，其他字符串运算符仍是文本输入。属性按“通用文件属性 → 文件大小”等、“图片属性 → 图片宽度”等展开，通用属性排在前面；只显示适用组与字段。中文显示与核心 ID 分开，既有目录外的值保留显示，不静默重写规则。

## 作业工作区

“活动”工作区的“作业队列”视图顶部一行显示运行/等待数量和刷新，没有页头标题。左侧执行槽位按配置数量纵向排列，每槽是一张横向卡片；编号来自核心实际分配，运行期间不因其他作业完成而上移。空槽保留占位；等待项独立成组；历史记录在下方分页并提供本页搜索/失败/取消筛选，不重复展示活动卡片。右侧固定详情列，840px 紧凑窗口仍保留所选作业详情；顶部刷新命令不随内容滚出视口。卡片不描边，用 `--shadow-card`，沿用 accent-wash 选中底色、进度条和状态文字；ID 在卡片截断，详情可完整复制。

并行数量、“应用”与“使用建议值”紧凑地放在“执行槽位”标题行右侧，可用逻辑处理器数量及“编码器内部也有线程”的说明收进旁边的提示。空槽位是一行高的虚线占位。只在队列空闲时启用，保存期间禁用，服务拒绝不预先改变槽位。当前页每 2 秒刷新，离开页面停止。观察作业与本会话底部作业栏分开；取消必须针对明确选中的 ID，不因切换页面或关闭观察窗口隐式取消外部作业。

## 资源过滤编辑器

来源路径下、步骤参数前分别放“来源过滤”“步骤过滤”，复用分组面板和控件令牌。标题旁的说明图标给出“来源排除不复制/备份、步骤条件读取当前产物”的解释，未设置条件时标题行右侧显示“未设置，全部通过”；不使用含糊的“智能过滤”。组内标签“且”、组间“或”，保留清除条件与单条删除，空条件明确全部通过。数字显示单位，不自动换算；属性选择只显示适用字段。宽编辑区一行排列属性/比较/值/删除，编辑区小于 520px 时属性独占一行；保留键盘标签及忙碌禁用，不产生水平溢出。以 1220×850 浅色和 840×620 深色原生截图验收。

## 排队提示

作业栏显示“排队等待”，作业中心提供等待原因、执行槽位和登记顺位（含执行中，不代表启动顺序）。无冲突项可并行，等待项仍可取消；不显示虚构预计完成时间，不把排队当成处理中。
