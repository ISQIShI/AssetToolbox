# ADR 0006：界面改为桌面软件外壳

状态：已采用。日期：2026-11-10。

关联：[前端设计规范](../design/frontend-design.md)、[前端架构](../architecture/frontend.md)、[ADR 0004](0004-frontend-redesign.md)、`desktop/src/`、`desktop/src-tauri/tauri.conf.json`、`desktop/src-tauri/capabilities/default.json`。

## 背景与约束

ADR 0004 确立了“处理线”主从结构、四个工作区和全局作业栏，这些信息架构运行良好。但它的视觉仍是网页的做法：系统标题栏下面还有一条带产品名和标签的页头，运行按钮在页脚，24px 标题配 1.6 行距和 720px 文章宽度，打包网页字体，固定浅色，文字可随意选中，按钮是手型光标，右键和 F5 是浏览器的行为。用户明确指出界面有“网页味”，要求按软件来设计，允许大范围修改且不保留兼容。

约束：继续支持核心桥接的全部功能；不改变协议、配置、任务和报告格式；原生窗口最小 840×620；CSP 不放宽；文件安全断言与原生 E2E 的行为断言不变。

## 决定

- **窗口框架**：原生窗口关闭系统边框（`decorations: false`），由前端绘制标题栏（应用图标、名称、当前来源文件夹、最小化/最大化/关闭）。为此在能力清单中增加 `start-dragging`、`minimize`、`toggle-maximize`、`internal-toggle-maximize`、`is-maximized` 五项窗口权限，不增加其他权限。
- **导航与命令**：页头标签改为左侧活动栏；处理页的运行栏从页脚移到顶部命令栏；窗口底部新增状态栏，显示当前活动、可继续的任务数和处理工具可用数。
- **密度与表单**：正文 13px、控件 30px；字段改为“标签在左、控件在右”的属性表单，相关字段放进分组面板；恢复结果是带工具栏和底栏的数据表。
- **字体**：改用系统界面字体（Segoe UI Variable / 微软雅黑 UI）与系统等宽字体，移除 `@fontsource/ibm-plex-sans` 和 `@fontsource/ibm-plex-mono` 依赖，EXE 不再携带 OFL 字体。
- **外观**：增加深色外观，默认跟随系统，可在活动栏一键切换；选择保存在 WebView `localStorage`，属于界面偏好，不写入核心配置。
- **桌面交互**：界面文字默认不可选中（路径、哈希、错误信息除外），箭头光标，悬停用底色；添加步骤改为浮动弹出菜单；增加 `Ctrl+1`–`4` 与 `Ctrl+S`；生产构建屏蔽浏览器右键菜单和刷新类快捷键。
- **图标**：新增一组自绘的单色线条图标（`Icon.vue`），不引入图标库。（下拉与提示的行为后来由 [ADR 0018](0018-headless-ui-primitives.md) 引入无样式库提供，外观不变。）

保留不变：处理线隐喻与站点语义、四个工作区、作业生命周期与 `core/workbench.ts`、界面词汇表、缺少依赖的品红标记（棋盘格图案随后换成了缺件图标）、测试使用的语义选择器与 `data-*` 钩子。

明确不包含：拖拽排序、步骤右键菜单、多窗口、系统托盘、手机宽度布局、协议或数据格式变更。

## 备选方案与取舍

- **保留系统标题栏，只换内部样式**：零原生风险，但窗口上方仍是“系统标题栏 + 页头”两层，是网页感最主要的来源。自绘标题栏的代价是失去 Windows 11 的贴靠布局悬停菜单，并需要原生验证拖动与缩放。
- **导航放进标题栏（居中分段）**：更省横向空间，但窗口 840px 时与窗口按钮、标题争位置；活动栏在增加工作区时也更容易扩展。
- **继续打包 IBM Plex**：字形统一，但与系统其他软件不一致，且随 EXE 分发需要附带 OFL 文本。系统字体没有分发义务。
- **只做深色或只做浅色**：实现更少，但桌面软件应跟随系统外观；令牌成对维护的成本可以接受。
- **用操作系统原生控件（WinUI）重写**：最“原生”，但要放弃现有 Vue 前端与测试，超出本次范围。

## 影响与验证

- 所有视图与组件的模板、样式重写，令牌改名（`--canvas/--paper/--ink…` → `--chrome/--pane/--surface/--control/--text…`）；`core/` 的状态、请求和纯函数不变，新增 `core/theme.ts`。
- 组件测试与原生 E2E 的选择器保持可用；新增快捷键、状态栏与外观切换的组件测试。验证结果见[项目状态](../project-status.md)。
- 用户可见文字变化：“选择…”改为“浏览…”；任务列表的“刷新”改为图标按钮；新增“外观”按钮与状态栏文字。用户说明同步更新。
- 第三方声明移除字体条目；前端依赖减少两个包。
- 回退方式：还原本次提交。配置、任务和报告格式未变，不涉及数据迁移；`localStorage` 中的外观选择可忽略。
