## 当前基线

## 已知限制

- 已确定并修复能稳定产生历史同类失败的锁竞争，新增 5 项回归；历史两次没有完整 worker 错误，无法逐次追溯证明其唯一原因，证据边界见本轮记录。
- 服务跟随原启动入口退出；仅管理通过 service-start 创建的安装级监听器，手动 policy/token 前台监听器独立。Agent 管理需 policy/2 显式授权并与配置等权。
- CPU 建议为可用逻辑处理器数除以 4、向下取整并限于 1–4；它不是性能基准或线程/内存配额。编码器内部线程仍独立管理，默认并行数不会自动改变。
- 同一安装协调资源；不同安装及外部编辑器仍需人工协调。没有常驻后台接管、崩溃自动重放或运行中自动调节预算。
- 历史作业同步扫描、筛选限于当前页；大报告先完整读取再分页，尚无索引或流式读取。
- [二进制分发](distribution.md)尚未放行；JPG-C 授权及其他工具的对应源码/组件许可义务不能用本地可运行代替。未接入 Cordis。
