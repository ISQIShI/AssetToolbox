# ADR 0017：代码属性目录与共享过滤器

状态：已采用。日期：2026-11-15。修订 [0003](0003-processing-contract.md)、[0007](0007-operation-adapters.md)、[0011](0011-unified-application.md) 的目录/持久化/应用版本，保留其提供方和入口边界。

## 背景

来源与各处理操作需要按文件大小、格式、图片分辨率等选择资源。把读取与判断分别放进界面或提供方会重复实现，并让来源排除、步骤跳过、任务续跑和备份恢复产生不同含义。

## 决策

- 增加独立 properties 属性组；通用组自动关联全部资源，专属组由类型声明。代码同步只读获取，目录公布类型、单位、运算符和版本。
- 使用有界 filter/1 表达式，OR 组内 AND；不接受用户脚本。规范化填属性版本，未知/旧版本拒绝。不可用属性不匹配，读取失败明确报错。
- sourceFilter 在固定 plan 前排除文件；step.filter 在适配器前读取当前中间产物。续跑不重新选择，恢复不隐式继承过滤器。
- 应用/响应升级 /8、HTTP /api/v8、job/6、settings/3、task/report/2、目录 API 4；拒绝旧数据且不迁移。备份普通文件保留，旧任务备份可独立导出。
- 全部入口复用 capabilities、validate 和 submit，无需新增平行处理动作；桌面使用共享编辑器，CLI 增加快捷参数，MCP 两传输从公共 schema 生成工具。

## 取舍与替代方案

选择有限 AND/OR 而非任意表达式语言，便于严格校验、可视化编辑和跨入口复现；未来复杂嵌套需新版本。选择独立属性组而非每个操作重复读取，便于共享和后续音频属性扩展。PNG/JPEG 首批用有界文件头读取，避免来源预览绑定编码器，但只承诺头部尺寸且暂不解释 PNG eXIf。

不把恢复候选列表接入素材过滤器：恢复目标是找回已修改内容，重新按当前属性选取可能漏掉必要备份。仍保留文本/状态展示筛选与显式哈希勾选。

## 后果与验收

属性插件仍为可信本地代码，不构成 OS 沙箱；读取器需控制成本、保持只读并升级语义版本。旧入口必须停用后成套升级。当前规则、错误语义和测试位置见[属性与过滤器](../architecture/properties-and-filters.md)；实际验收见[验证记录](../verification/2026-11-15-resource-filters.md)。
