## 音频分析、增益与响度归一化（本轮）

- 新增 WAV/FLAC/Ogg 类型及三个音频操作，FFmpeg 一个提供方按操作组织适配器；支持 MP3、WAV PCM、FLAC、Ogg Vorbis/Opus。详见[音频专题](architecture/audio.md)。
- 分析只读，记录 LUFS、采样/真峰值、LRA、时长及格式；只分析的文件不复制、备份或写提交意图。任务、取消和结果仍沿用现有设施。混合流水线可分析转换前后，后续失败不提交中间产物。
- 增益/归一化只应用整段固定增益；超峰限制或报错，编码后复测，不自动启用动态压缩/限幅。默认另存，覆盖必须备份。短音/静音不做不可靠归一化；前端明确展示未达目标、损失与未提交结果。
- 目录 API 3、操作 API 2 增加 observe/preserveOriginal，提供方仍 API 2；配置 /2、任务及报告外层 /1 不变。新增 [ADR 0008](decisions/0008-audio-observation.md)，同步指南、协议、架构和文档索引。
- 工具页展示 FFmpeg/FFprobe 9.0.2 官方推荐 Gyan 渠道和手动安装指引。该发行包不符合现有自动安装器的大小/归档范围，未削弱校验。两个 EXE 仅留本地，记录本地摘要、版本、GPLv3 文本、构建配置及源提交；未重新核验发行归档，二进制分发仍未放行。
- 作业栏展示最多 100 条测量结果；完整明细写入 report.json 与 audio.csv。新配置默认另存，已有 /2 配置保留显式设置。

### 环境处置与当前边界

- 原阻碍来自 SAC 的 VerifiedAndReputableDesktop 策略拦截 Rust 宏 DLL（Windows 4551），不应据事件中的 Enterprise 字样认定为组织管理。用户自行关闭 SAC 后，本次只读确认状态为 0、对应策略不再 Enforced；未由项目脚本修改安全设置。未实施的[独立开发环境方案](archive/windows-native-validation-vm.md)已归档，不属于待办。
- 原生 E2E 明确清除 ASSET_TOOLBOX_AUDIO_BROWSER，直接启动新 EXE。当前结果验证本机环境下的功能，不代表未签名产物已获得 SAC 信任；重新启用 SAC 或对外分发时仍需另行核对签名与环境条件。
- 不支持多音轨/环绕声、跨格式转换、动态压缩、波形编辑或 FFmpeg 自动安装。每次 FFmpeg 调用有 120 秒限时；测量精度及质量边界见音频专题。
- 有损格式非零处理会重新编码，标签/封面/循环标记不保留；建议使用无损母版，并保留原文件。源仓库仍为 MIT，第三方工具遵循各自许可；本轮只做本地提交，未推送或发布二进制。

## 多操作提供方契约（上一轮）

- 提供方通过 adapters 按操作登记独立资源类型、参数 schema、版本和 execute；注册器生成支持关系，拒绝 API 1 及旧顶层接口。四个内置提供方全部迁入 adapters 目录，原功能范围不变。
- 引擎按操作选择适配器并传入 operation；共享依赖与每作业一次 prepare 留在提供方层。参数、默认值、验收策略和执行结果按步骤隔离；后续步骤失败仍丢弃整条处理线产物。
- 目录 API 2 输出各适配器字段，前端仅显示当前操作的工具参数。同操作切换工具保留公共参数，专属参数使用目标默认值；跨操作重置两组。步骤 ID、启用状态与顺序保留，旧版本快照清除后重新生成。
- 步骤 versions 新增 adapter；配置升级 asset-toolbox.settings/2，不迁移或重写旧 /1。旧三字段快照拒绝继续处理；任务/报告外层 /1 不变，备份恢复不依赖适配器。
- 更新扩展契约、前后端/协议/持久化、AGENTS、用户说明、索引，并新增 [ADR 0007](decisions/0007-operation-adapters.md)。

## 仍有的边界与后续方向

- 目前同格式、一入一出、逐文件串行，扩展为可信本地代码；无热重载、依赖注入或权限沙箱。版本匹配依赖开发者正确升级版本，不是代码哈希校验。
- 工具执行无强制超时，取消在文件边界生效；Sharp 每文件启动子进程有开销。大任务内存和日志重放尚未做性能基准。
- 缩放首版仅静态 PNG/JPEG，最大 4000 万像素；音频调整、格式转换、多输出仍待需求实现。
- 便携分发须携带核心 node_modules。构建脚本不生成独立分发压缩包，来源/许可记录已建立，剩余二进制放行条件见上方本轮记录。
- 没有 CI、lint、覆盖率门槛、日志自动清理或全局素材锁。文件安全是单文件保证，不是整批事务。

后续功能按扩展契约添加操作与提供方，先补真实输出和失败保护测试；出现共享服务或生命周期管理需求时，再单独评估 Cordis，当前不预装。
