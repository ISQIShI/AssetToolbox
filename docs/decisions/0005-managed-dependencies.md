# ADR 0005：核验清单与不可变依赖安装

- 状态：已采用
- 日期：2026-11-09

## 背景

源码仓库不携带第三方二进制，用户需要从界面补齐可自动获取的工具，同时防止任意地址下载、供应链内容变化和更新破坏运行中的任务。

## 决策

内置固定版本、来源和摘要的核验清单，只开放 LAME 与 Sharp 的 Windows x64 安装。pngquant 和 JPG-C 保留手动获取。更新随项目清单审核，不接受远程未经审核的 latest；前端只传提供方 ID。

安装器使用独立进程，复用全局作业进度与取消。先校验归档摘要、限制解包范围、检查运行能力，再原子切换 UUID 安装目录的启用记录。保留旧安装与手动文件，处理作业固定依赖路径；不运行 npm 脚本。

## 取舍

新增了一套受限制的 ZIP/TAR 读取和文件清单校验，必须保留恶意归档、损坏下载、取消与失败保护测试。不可变目录占用更多磁盘，暂不自动回收或提供回退按钮。审核清单更新速度慢于上游，但不会将未核验构建悄悄交给用户执行。

不采用覆盖原文件安装，避免锁定 DLL、半更新和跨实例读取混合版本；不采用安装器内执行 npm/Cargo，避免要求额外工具链及执行未经核验的安装脚本。未来如引入远程更新清单，须另行设计签名、密钥轮换及防降级机制。

详细实现与边界以[依赖管理专题](../architecture/dependencies.md)为准。第三方分发许可要求不因自动下载而改变。
