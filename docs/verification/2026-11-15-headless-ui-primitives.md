# 无样式组件库与下拉、提示封装验收

日期：2026-11-15。基线 `1b9e3f2`。用户确认引入 Reka UI 作为行为层并按“先下拉与提示”的范围推进；外观、令牌、核心、协议与数据格式不变。决策见 [ADR 0018](../decisions/0018-headless-ui-primitives.md)。

## 变更与边界

- 新增运行依赖 `reka-ui` 2.11.0（精确锁定），安装时使用 `--ignore-scripts`。
- 新增 `SelectBox.vue`、`Tip.vue` 两个封装；视图不直接引入 `reka-ui`。弹出列表与提示的样式在 `styles/base.css`，只引用令牌。
- 10 处原生 `<select>` 全部替换：步骤编辑器的资源格式、操作、处理工具；枚举参数；过滤编辑器的属性、比较、目录值、布尔值；恢复页的任务；作业中心的状态筛选。
- 按钮上的 `title` 换成 `Tip`：活动栏（带 `Ctrl+数字`）、外观按钮、信息条与作业栏的关闭、命令栏的保存配置（带 `Ctrl+S`）/扫描预览/写入策略、任务页的刷新/继续/重试、步骤选择器的返回。
- 保留原生 `title` 的三处：作业卡片的完整编号、步骤选择器里操作的描述、存储维护的勾选项说明。“添加步骤”选择器没有迁移到 Reka。
- 组件测试改为通过 `SelectBox` 的公开接口操作（`tests/select.ts`）；三个原生用例里的 12 处 `selectOption` 改为真实点开并点选（`tests/native-select.ts`）。其余断言未改。

## 未执行与限制

- 核心全量、MCP 独立包、联网 E2E（`test:e2e:network`）未运行：本轮没有修改对应代码。
- 下拉框的键盘操作（方向键、键入定位、Esc）没有自动化用例，也没有在原生窗口里人工逐项确认；它们由 Reka UI 实现。
- 浏览器预览工具的点击不产生指针事件，预览中的展开是用脚本派发 `pointerdown` 触发的；真实点击由原生 E2E 覆盖。
- 停用的按钮不会显示提示（浏览器不向停用按钮派发指针事件），停用原因仍需由周围文字说明。
- 传递依赖中有三个 Apache-2.0 包，二进制分发时须附带许可证文本；二进制分发本身仍未放行。
