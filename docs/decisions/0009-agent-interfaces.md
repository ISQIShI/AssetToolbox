# ADR 0009：共享应用接口、CLI 与本地 MCP

状态：已采用；入口统一和 HTTP 支持由 [0010](0010-local-http.md) 补充。日期：2026-11-10。部分修订 [0001](0001-local-process-architecture.md) 的入口划分及 [0005](0005-managed-dependencies.md) 的跨实例并发行为。下文“暂不做 HTTP”保留为首版决策背景，不是当前能力限制。

> 后续修订：[0011](0011-unified-application.md) 完整统一公共作业契约；本文的桌面临时作业/专用分支描述仅保留为历史决策。

## 背景

外部 Agent 需要发现能力、执行各种资源操作并可靠获取结果。原直接 CLI 只有一次扫描/转换，桌面桥接只有当前进程会话；两者缺少统一目录授权、作业查询和幂等语义。单任务锁无法阻止不同新任务处理同一素材。

## 决策

新增 CommonJS 应用服务，抽出共享 JobSession，复用既有批处理、任务日志、恢复与依赖安装。提供 JSON CLI API，以及独立 npm 包中的官方 SDK stdio MCP 适配；MCP 直接调用服务，不通过 shell。目录、操作和适配器仍由现有扩展注册器负责。

启动权限固定素材/输出/备份范围，覆盖必须授权并备份；恢复必须明确选择预览哈希，依赖安装单独授权。外部请求使用 taskId/jobId，不接受任意任务元数据路径或下载地址。新增 /1 应用响应、自动化权限与持久作业格式；不改变素材任务 /1 或设置 /2。

同权限范围的幂等键防重复提交；GUI、CLI、MCP 共用按安装划分的进程锁。取消保持文件边界语义；客户端断开不创建无人管理的常驻进程。长作业通过 submit/status/cancel 表达，不依赖 MCP 的可选长任务扩展。

## 代价与替代方案

CLI 适合脚本和构建，MCP 提供 Agent 工具发现；两入口增加少量维护与测试，但参数、策略和执行统一。官方 SDK 独立安装，避免增加桌面运行依赖。全局串行牺牲同一安装的吞吐，先换取明确的写入边界；以后可按实际需求设计路径级锁。

暂不做 HTTP/OpenAPI、鉴权服务、常驻队列或多用户执行，避免本地工具承担尚无需求的服务运维。直接暴露 engine SDK 缺少任务与权限约束，不作为外部 Agent 契约；UI 自动化仅用于验收。当前应用权限不替代操作系统隔离，详见[自动化专题](../architecture/automation.md)。
