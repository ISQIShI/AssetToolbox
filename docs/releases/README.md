# 版本说明

每次准备发布时新增 `<VERSION>.md`，提交后由对应标签的 Release 工作流读取。这里只保存对使用者有意义的发布说明；逐轮测试证据继续放在[验证记录](../verification/README.md)，现状放[项目状态](../project-status.md)。规则与操作见[发布流程](../releasing.md)。首版说明：[v1.0.0](1.0.0.md)；发布状态见项目状态与 GitHub Releases，不将说明文件本身视为发布成功。

以下模板须替换示例版本并填入实际内容；脚本拒绝缺少标题、空章节或 `TODO`、`TBD`、`待填写`、`待补充` 字样。版本说明会原样放入 GitHub Release，链接使用完整 GitHub URL，避免相对链接在 Release 页面失效。

```markdown
# v1.0.0-rc.1

## 变更
用简短条目说明使用者能感知的新增、修复和行为变化。

## 兼容性
说明应用/API/配置/任务/提供方版本变化、拒绝策略和升级前操作；未变化时明确说明。

## 验证
列出真正执行的命令、结果和环境，附本版验证记录的完整 URL；单独列出未执行项及原因。

## 获取与限制
仅源码，仓库公开，项目自有代码 MIT；第三方依赖另行获取。说明如何构建、已知限制及依赖许可边界。
```
