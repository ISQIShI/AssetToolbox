## 已知限制

- 资源类别仅用于统一界面组织和筛选，步骤仍指定一个格式；本轮按用户选择未实现单步骤同时处理 JPEG/PNG。
- 多级菜单的点选、左右方向键、Esc、焦点及边界已有原生测试；对话框和右键菜单仍未逐项覆盖键盘操作，屏幕阅读器未人工验收。级联菜单没有跨层全文搜索；添加步骤支持当前层搜索。拖拽排序不会在滚动区边缘自动滚动，停用的按钮不显示提示。
- 拖入文件夹和“打开文件夹”没有原生自动化用例。数值参数没有单位后缀与宽高锁定（字段描述里没有对应信息）。任务体积只统计已完成的文件，恢复原文件后不回退。工具页结构未调整。

- 图片属性尚未解释 PNG eXIf。音频专属属性支持普通 PCM/浮点 WAV、部分 RF64、原生 FLAC。MP3、Ogg 仍只有通用字段。RF64 可跳读大块元数据，实际转换仍整文件读入内存。
- 扫描只应用来源过滤，不执行转换来预测步骤条件。属性读取失败明确报错，来源排除不复制或备份；步骤全部跳过时另存仍复制原文件。
- 服务跟随原启动入口退出；仅管理通过 service-start 创建的安装级监听器，手动 policy/token 前台监听器独立。Agent 管理需 policy/2 显式授权并与配置等权。
- CPU 建议为可用逻辑处理器数除以 4、向下取整并限于 1–4；它不是性能基准或线程/内存配额。编码器内部线程仍独立管理，默认并行数不会自动改变。
- 同一安装协调资源；不同安装及外部编辑器仍需人工协调。没有常驻后台接管、崩溃自动重放或运行中自动调节预算。
- 历史作业同步扫描、筛选限于当前页；大报告先完整读取再分页，尚无索引或流式读取。
- [二进制分发](distribution.md)尚未放行；JPG-C 授权及其他工具的对应源码/组件许可义务不能用本地可运行代替。未接入 Cordis。
- 云端源码 CI 与本机编码器/原生验收分层执行，仓库保护规则尚未启用。历史网络 ECONNRESET 的原因尚待核实。

## 下一步（建议，尚未实施）

1. **作业状态可信度**。桌面 `poll()` 遇到查询异常会在本地生成失败终态。分别模拟暂时断连、结果分页失败及真实 worker 退出，验证在重新取得权威终态前仍能观察原作业并安全退出。
2. **历史增长后的响应时间**。队列在提交锁内扫描历史，桌面每次刷新另查一页状态。以 100、1,000、10,000 个合成历史作业测量提交锁持有时间、首屏与刷新耗时，再决定是否合并状态查询或增加可重建索引。
3. **任务首次发布**。`tasks.js` 先创建任务目录再写主记录。用双进程门闩验证创建中列表的可见性，再评估复用已有原子目录发布机制。
4. **素材属性查看与过滤预设**。先在扫描结果解释文件为何命中，用真实短音效验证工作流，再支持复用带版本的条件。MP3/Ogg 时长与 PNG eXIf 另需定义读取预算与未知值行为。
