# ADR 0020：合并“任务”与“作业”为活动工作区，数值控件，撤回窗口材质

状态：已采用。日期：2026-11-15。部分取代 [ADR 0019](0019-inspector-and-window-material.md) 中的“窗口材质”一项。

关联：[前端设计规范](../design/frontend-design.md)、[前端架构](../architecture/frontend.md)、[作业中心](../architecture/job-center.md)、`desktop/src/views/ActivityView.vue`、`desktop/src/components/NumberField.vue`。

## 背景与约束

- ADR 0019 在 Windows 11 上让窗口框架透出 Mica 材质。用户在实机上看到的结果是：框架随壁纸带上绿色和暖色的色调，与工作区的冷灰色不协调，整体风格不统一，要求去除。
- 活动栏有“任务”和“作业”两项，图标相近、概念相邻：任务是按来源文件夹保存的处理进度，作业是各入口提交的一次次运行。用户要先弄清两者的区别才知道去哪一页。作业页顶部的“统一作业中心”“保持各自的运行会话”是工程用语，并行设置和空槽位占了大半屏。
- 恢复页选中任务后还要再点一次“检查备份”。
- 参数里的数值一律是原生数字框，质量、级别这类有限范围的参数只能手输。

约束：不改变核心、协议与数据格式；作业仍只经公共动作观察和取消，观察状态独立于本会话作业；并行预算仍只在队列空闲时由受信任本地上下文修改；参数表单仍只按核心返回的字段描述渲染，前端不内置任何参数的语义；原生 E2E 的安全断言保持。

## 决定

- **撤回窗口材质**：窗口恢复为不透明，框架用 `--chrome`。删除 `core/material.ts`、`transparent` 与 `windowEffects` 配置、原生窗口主题同步和 `core:window:allow-set-theme` 权限。不再按系统版本区分外观。
- **活动工作区**：活动栏改为四项——处理、活动、恢复、工具（`Ctrl+1`–`4`）。“活动”里用顶部的分段选择切换“任务”与“作业队列”两个视图，原有的 `TasksView` 与 `JobsView` 作为子视图保留各自的状态和轮询。内部页面标识仍是 `tasks` 与 `jobs`，再次进入时回到上次看的视图；“查看任务”等入口直接落在任务视图。
- **作业队列精简**：去掉页头标题和说明；并行数量、应用、建议值收进“执行槽位”标题行右侧，解释放进提示；空槽位改为一行高。并行设置没有移到单独的设置页——它只在看得到槽位时才有意义，改完立刻要看槽位数量变化。
- **恢复页**：在“任务的备份”里选中任务即开始检查；按钮改为“重新检查”。同一任务已有结果时不重复提交。独立备份仍需填好两个文件夹后手动检查。
- **数值控件**（`NumberField`）：数字框右侧带一对步进按钮；字段同时声明了上下界且档位不超过 200 个时，左侧配一个滑块。数字框是唯一带标签、可聚焦的控件，滑块和步进按钮是鼠标辅助，不进入 Tab 顺序和无障碍树。步进结果按声明的小数位取整并夹在范围内；手动输入的越界值原样上报，由表单提示。

明确不包含：宽高“锁定比例”——前端不知道哪两个字段是一对宽高，要做就得在操作契约里声明字段关系；而图片缩放的“适应方式”已经提供等比适应。参数单位后缀——字段描述里没有单位。任务详情里的体积统计与“打开文件夹”——任务摘要没有体积字段，打开路径需要新的原生命令。这些都需要先改契约，另行决定。

## 备选方案

- **保留 Mica，只调淡或改成 Acrylic**：色调仍来自壁纸，无法保证与界面一致。
- **保留两个活动栏项，只换图标和名称**：改动最小，但仍要用户在导航层区分两个相邻概念。
- **把任务和作业合成一张列表**：两者不是一一对应（一个任务可以有多次续跑、重试和恢复作业，预览作业没有任务），合并列表会混淆“可继续的进度”和“一次运行的记录”。
- **新增设置页放并行数量**：只有一项设置，且与槽位显示分离后，修改被拒绝或生效都看不到上下文。
- **滑块用组件库（Reka Slider）**：原生 `input[type=range]` 配合样式已够用，不增加依赖面。

## 影响

- 兼容性：核心、协议、数据格式不变。活动栏少一项，`Ctrl+5` 不再有效；用户指南同步更新。需要重新构建 EXE。
- 安全：权限减少一项（窗口主题）。并行预算的权限与空闲约束不变。
- 可靠性：窗口不再依赖系统材质与版本判断，去掉了“材质未生效时框架透出桌面”的风险。
- 维护：新增 `ActivityView.vue`、`NumberField.vue`；`Page` 类型不变。测试钩子不变（`.dock`、`.job-row`、`.slot`、`并行数量` 标签等）。
- 测试：组件测试覆盖活动页的切换与记忆、恢复页选中即检查且不重复提交、数值控件的步进、夹取、取整与滑块出现条件；原生 E2E 改为经“活动”进入任务与作业队列，其余断言不变。
