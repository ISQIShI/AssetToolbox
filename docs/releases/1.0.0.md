# v1.0.0

## 变更

AssetToolbox 资源工具箱首个公开源码版本，面向 Windows x64 游戏资源处理与本机 Agent 自动化。

- 图片：PNG/JPEG 压缩、等比缩放、裁剪填充与拉伸。
- 音频：WAV/FLAC/MP3/Ogg 分析、固定增益、响度归一化，以及 MP3 压缩；超峰限制或报错，不自动动态压缩。
- 任务：可排序处理步骤、属性过滤、预览、另存/备份覆盖、取消、续跑、失败重试和选择性恢复。
- 自动化：统一桌面、CLI、MCP stdio、MCP Streamable HTTP 与本机 HTTP API；资源感知队列支持 1–8 项并行，默认 2。
- 独立用户文档：快速开始、使用、工具安装、MCP 配置、CLI/HTTP、开发部署和排错。
- 版本发布由标签触发 CI，检查通过后自动创建 GitHub Release。

## 兼容性

本版建立首个产品兼容性基线：应用/响应 /8、HTTP /api/v8、job /6、settings /3、task/report /2、目录 API 4、提供方 API 2、policy /2。开发阶段的旧契约数据明确拒绝，不自动迁移；已有备份可用独立备份导出。

桌面、核心与 MCP 必须成套使用。HTTP 仅监听本机，不提供公网或多用户账户服务；进程退出会请求取消自己持有的作业。当前不支持跨格式转换。

## 验证

Windows x64，开发 Node 26.13.0、便携 Node 24.19.0、Rust 1.99.1：核心全量 178 项、前端 61 项、发布工具 5 项通过，类型检查及原生 release 构建通过，新 EXE 的原生 E2E 3 项通过。MCP 完整复测 7 项通过；首次运行发生一次跨入口状态查询断言失败，已增加响应诊断但未证明根因修复，保留为已知间歇性问题。

本轮未重新执行联网依赖安装 E2E，安装清单与实现未变。源码 CI 是发布前置门槛，不代替本机真实编码器和原生验收。详细证据见[首版验证记录](https://github.com/ISQIShI/AssetToolbox/blob/v1.0.0/docs/verification/2026-11-15-public-first-release.md)。
